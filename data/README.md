# Data

The recordings used in the original work are **not distributed** with this repository because they show people, and their provenance and terms of use are not documented. To run the notebook, place your own videos in `data/videos/`. The notebook expects these file names:

| File name | Used in notebook section | Clip length |
|---|---|---|
| `recording_1.mp4` | I-VIII (main analysis and neutral-region control) | 30 s |
| `recording_2.mp4` | IX | 10 s |
| `recording_3.mp4` | X | 30 s |

Or edit the file names (and the hard-coded clip durations) in the notebook. The notebook assumes 30 frames per second and a mouse-selected region of interest; the coordinates used for the saved outputs are listed in the notebook introduction.
